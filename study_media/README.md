# Study media

Study videos are deliberately not distributed with this repository. Add MP4 files to:

- `study_media/control/`
- `study_media/treatment/`

The platform serves each folder as a deterministic ordered Shorts sequence. Files are sorted by filename unless a generated `sequence_manifest.csv` is provided. Use filenames with numeric prefixes, such as `001-introduction.mp4`, to control order.

Only use media you have the legal and ethical right to distribute and expose to participants. Never commit participant data or restricted study media to a public repository.
